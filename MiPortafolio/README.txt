MI PORTAFOLIO — GUSTAVO LÓPEZ HERNÁNDEZ

1. Abre la carpeta MiPortafolio en Visual Studio Code.
2. Abre index.html en el navegador o usa Live Server.
3. Coloca tres imágenes para cada proyecto dentro de assets con estos nombres:
   sazon-1.jpg, sazon-2.jpg, sazon-3.jpg
   restaurant-1.jpg, restaurant-2.jpg, restaurant-3.jpg
   fisioapp-1.jpg, fisioapp-2.jpg, fisioapp-3.jpg
   consultoria-1.jpg, consultoria-2.jpg, consultoria-3.jpg
4. Las imágenes deben ser capturas propias y pueden ser JPG, PNG o WEBP.
   Si cambias la extensión, actualiza también la ruta en index.html.
5. Si una imagen aún no existe, su espacio aparecerá vacío hasta que la agregues.
6. Para activar el formulario de correo, cambia CONTACT_EMAIL en script.js.
   El formulario abre la aplicación de correo del visitante; no envía mensajes a un servidor.
7. Antes de publicar, comprueba que no haya contraseñas, claves ni datos privados en los archivos.

Cada tarjeta tiene un carrusel independiente: flechas izquierda/derecha e indicadores inferiores.
